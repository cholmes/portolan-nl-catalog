# National Monuments (Rijksmonumenten)

Point locations of all 63,073 nationally listed monuments (rijksmonumenten) in the Netherlands. These are buildings, objects, and sites protected under the Heritage Act (Erfgoedwet) for their beauty, scientific significance, or cultural-historical value. 98% are built structures; 2% are archaeological sites. About 22% belong to a complex (ensemble of related monuments). Published by the Cultural Heritage Agency (RCE) via PDOK.

## Schema

| Column | Type | Description |
|--------|------|-------------|
| rijksmonum | float64 | Monument registration number (primary key) |
| complex_nu | float64 | Complex number — groups related monuments (null for standalone) |
| juridische | string | Legal status (always 'rijksmonument') |
| aard_monum | string | Monument nature: 'archeologisch' or 'onroerend gebouwd' |
| herkomst | string | Source of point geometry: BAG, BRK, RCE handmatig, etc. |
| kwaliteit_ | string | Location quality: 'exact', 'globaal' (approximate), 'besluit' |
| hoofdcateg | string | Main category: Woningen, Boerderijen, Kastelen, etc. (13 categories) |
| subcategor | string | Subcategory: Woonhuis(K), Boerderij(M), Kerk, etc. (66 values) |
| rijksurl | string | URL to monument register page |
| geometry | binary | Point in EPSG:28992 (RD New), WKB encoded |

## Quick Start

```python
import geopandas as gpd
gdf = gpd.read_parquet('rijksmonumenten.parquet')
castles = gdf[gdf['hoofdcateg'] == 'Kastelen, landhuizen en buitenplaatsen']
```
