# Buildings (INSPIRE Harmonized)

All buildings in the Netherlands from the BAG (Basisregistratie Adressen en Gebouwen), harmonized to the EU INSPIRE Buildings schema. Contains 24.2 million building footprint polygons with construction dates and BAG identifiers. Includes both current and historical versions — records with endLifespanVersion = null are the current version. Published by Kadaster via PDOK.

## Schema

| Column | Type | Description |
|--------|------|-------------|
| OGC_FID | int64 | Internal feature ID from WFS extraction |
| gml_id | string | GML feature identifier (format: nl-imbag-bu.<localId>.<version>) |
| beginLifespanVersion | string | When this version of the record was inserted into the dataset (ISO 8601 datetime) |
| anyPoint | string | Construction date (dateOfConstruction.anyPoint in INSPIRE schema, ISO 8601). Value of 9999-01-01 means planned/unknown. |
| endLifespanVersion | string | When this version was superseded (null = current version, non-null = historical) |
| localId | int64 | BAG building identifier (pand ID). Unique across versions; multiple rows per localId represent version history. |
| namespace | string | INSPIRE namespace, always 'nl-imbag-bu' |
| referenceGeometry | bool | Whether this is the primary geometry representation (always true) |
| horizontalGeometryEstimatedAccuracy | string | Estimated horizontal accuracy in meters (not populated in this dataset) |
| verticalGeometryEstimatedAccuracy | string | Estimated vertical accuracy in meters (not populated in this dataset) |
| end | string | dateOfConstruction.end — end of construction period (not populated; use anyPoint instead) |
| beginning | string | dateOfConstruction.beginning — start of construction period (not populated; use anyPoint instead) |
| geometry | binary | Building footprint polygon in EPSG:4258 (ETRS89), WKB encoded |

## Processing Notes

INSPIRE-harmonized buildings from BAG, downloaded via PDOK WFS (https://service.pdok.nl/kadaster/bu/wfs/v1_0) using gpio extract wfs in a tiled grid. Tiles merged with DuckDB, then optimized with gpio (Hilbert sort + bbox covering columns). Original GML.gz from PDOK ATOM download service included as additional asset.
