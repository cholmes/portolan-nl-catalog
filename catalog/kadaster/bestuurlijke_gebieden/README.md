# Administrative Areas (Bestuurlijke Gebieden)

The official administrative boundaries of the Netherlands: 342 municipalities (gemeenten), 12 provinces (provincies), and 1 national territory (landgebied). Updated annually on January 1st to reflect municipal mergers. Published by Kadaster via PDOK. This is the authoritative reference dataset for Dutch administrative boundaries — CBS municipality/province codes from this dataset are used across all Dutch government data. 2026 edition.

## Schema

| Column | Type | Description |
|--------|------|-------------|
| fid | int64 | Internal feature ID |
| identificatie | string | CBS code — 4-digit municipality code, province identifier, or country identifier |
| naam | string | Name of the administrative area |
| code | string | Prefixed code: GM0363 (gemeente), PV27 (provincie), LND6030 (land) |
| ligt_in_provincie_code | string | Province code (gemeentegebied only) |
| ligt_in_provincie_naam | string | Province name (gemeentegebied only) |
| ligt_in_land_code | string | Country code (provinciegebied only) |
| ligt_in_land_naam | string | Country name (provinciegebied only) |
| geometry | binary | Boundary polygon in EPSG:28992 (RD New), WKB encoded |
