# Buildings (Panden)

All 11.4 million buildings (panden) in the Netherlands from the BAG (Basisregistratie Adressen en Gebouwen), the authoritative Dutch national building registry. This is the official BAG GeoPackage 'light' extract from PDOK/Kadaster, containing current buildings only (no version history). Includes building footprints, construction year, lifecycle status, primary usage function (gebruiksdoel), floor area, and number of dwelling units. Native CRS is EPSG:28992 (RD New / Amersfoort). Published monthly by Kadaster via PDOK.

## Schema

| Column | Type | Description |
|--------|------|-------------|
| identificatie | string | BAG building identifier (16-char pand ID). First 4 digits encode the municipality code (gemeentecode). Unique per building. |
| bouwjaar | int64 | Original construction year (oorspronkelijk bouwjaar). Integer year (e.g., 1975). Value of 9999 means unknown. Does not change with renovations. |
| status | string | Building lifecycle status (pandstatus). Most common: 'Pand in gebruik'. Other values: 'Bouwvergunning verleend', 'Bouw gestart', 'Verbouwing pand', 'Sloopvergunning verleend', 'Pand in gebruik (niet ingemeten)', 'Pand buiten gebruik'. |
| gebruiksdoel | string | Primary usage function of the building, derived from contained dwelling units (verblijfsobjecten). Values include: 'woonfunctie' (residential), 'industriefunctie' (industrial), 'kantoorfunctie' (office), 'winkelfunctie' (retail), 'logiesfunctie' (lodging), 'bijeenkomstfunctie' (assembly), 'onderwijsfunctie' (education), 'gezondheidszorgfunctie' (healthcare), 'sportfunctie' (sports), 'overige gebruiksfunctie' (other). Can be comma-separated for mixed use. NULL when building has no verblijfsobjecten. |
| oppervlakte_min | int64 | Minimum floor area (m²) of contained dwelling units (verblijfsobjecten). NULL when building has no verblijfsobjecten. |
| oppervlakte_max | int64 | Maximum floor area (m²) of contained dwelling units. Equals oppervlakte_min when building contains exactly one dwelling unit. |
| aantal_verblijfsobjecten | int64 | Number of dwelling units (verblijfsobjecten) in the building. 0 = no addressable units (shed, garage). Higher values = apartment building or mixed-use. |
| rdf_seealso | string | Linked Data URI for this building in the BAG knowledge graph. |
| geom | binary | Building footprint polygon in EPSG:28992 (RD New / Amersfoort), WKB encoded. Coordinates in meters. |

## Processing Notes

BAG GeoPackage 'light' extract downloaded from PDOK ATOM service (https://service.pdok.nl/lv/bag/atom/bag.xml). Pand table extracted to GeoParquet with gpio, preserving native EPSG:28992 CRS. Optimized with Hilbert sort and bbox covering columns.
