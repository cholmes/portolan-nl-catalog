# Natura 2000 Protected Areas

Boundaries of all 162 Natura 2000 protected areas in the Netherlands, designated under the EU Birds Directive (Vogelrichtlijn) and Habitats Directive (Habitatrichtlijn). Contains 209 features because some areas have separate features for different designation types (VR, HR, or VR+HR). Includes terrestrial and marine areas extending into the North Sea EEZ. Published by RVO via PDOK.

Natura 2000 areas carry the strongest nature protection in Dutch law — any plan or project that may affect them requires assessment under the Wet natuurbescherming.

## Schema

| Column | Type | Description |
|--------|------|-------------|
| id | int64 | Feature ID |
| naam_n2k | string | Name of the Natura 2000 area (Dutch) |
| nr | int32 | Official Natura 2000 area number (1-166) |
| vhn_new | int16 | Designation type: 1=VR (Birds), 2=HR (Habitats), 3=Both, 9=HR quarry |
| beschermin | string | Protection type as text: VR, HR, VR+HR, or HR groeve |
| sitecode_v | string | EU site code for Birds Directive (blank if HR-only) |
| sitecode_h | string | EU site code for Habitats Directive (blank if VR-only) |
| status | string | Legal designation status (free-text with date) |
| shape_area | float64 | Area per feature in m² |
| shape_len | float64 | Perimeter per feature in metres |
| geometry | binary | MultiPolygon in EPSG:28992 (RD New), WKB encoded |
