# National Parks (Nationale Parken)

Boundaries of all 21 National Parks in the Netherlands. Large contiguous natural areas of national and international importance, designated for their ecological, landscape, and recreational value. Parks range from coastal dunes and forests to wetlands, heathlands, and tidal estuaries. Managed by the provinces since the 2023 reform. Published by RVO via PDOK.

## Schema

| Column | Type | Description |
|--------|------|-------------|
| id | string | Unique identifier (UUID) |
| naam | string | Name of the National Park (Dutch) |
| nr | int32 | Sequential park number (chronological designation order, 1-22) |
| hectares | float64 | Area of the park in hectares |
| datum | string | Date of designation (ISO 8601) |
| bron | string | Source of the boundary |
| fiat_secr | string | Approved by the Secretary of State (Ja/Nee/blank) |
| instrument | string | Protection instrument type (always 'Nationaal Park') |
| geometry | binary | MultiPolygon in EPSG:28992 (RD New), WKB encoded |
