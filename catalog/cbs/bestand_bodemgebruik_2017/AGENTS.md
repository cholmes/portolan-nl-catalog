# Bestand Bodemgebruik 2017 (Land Use File)

Portolan collection — `cbs/bestand_bodemgebruik_2017`

Digital geometry of land use in the Netherlands (2017). Covers all functional land use at ground level: transportation, buildings, recreation, agriculture, forest, water. Boundaries are largely based on Top10NL/BRT topographic map. Aerial photographs from summer 2017 serve as the primary interpretation source. Uses a hierarchical classification system with approximately 40 land use types, typically with a 1-hectare minimum mapping threshold. This is the BBG 2017 (old methodology); from 2020 onwards CBS produces the NBBG (renewed methodology). Published by CBS (Centraal Bureau voor de Statistiek) via PDOK. Native CRS is EPSG:28992 (RD New / Amersfoort).
