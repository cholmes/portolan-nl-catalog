# Bevolkingsspreiding (Population Distribution)

Portolan collection — `cbs/bevolkingsspreiding`

INSPIRE-harmonized population distribution dataset from CBS, containing the number of inhabitants per municipality (LAU), province (NUTS2), and 1km² grid cells according to the European ETRS89-LAEA coordinate system (EPSG:3035). This is the Dutch contribution to the European INSPIRE Statistical Units / Population Distribution theme. Three feature types are available: 1km² grid cells (pd-nl-grid-2012), NUTS2 provinces (pd-nl-nuts2-2018), and LAU municipalities (pd-nl-lau-2018). Reference years: grid 2012, NUTS2/LAU 2018.
