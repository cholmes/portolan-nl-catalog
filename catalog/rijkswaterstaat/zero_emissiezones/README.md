# Zero Emission Zones

Zero emission zones (zero-emissiezones) in Dutch cities where only emission-free vehicles are allowed. 42 MultiPolygon features covering Low Emission Zones (LEZ) and Zero Emission Stadslogistiek (ZES) areas.

## Schema

| Column | Type | Description |
|--------|------|-------------|
| OBJECTID | int64 | Feature ID |
| Naam | string | Zone name (e.g. "LEZ 's-Hertogenbosch") |
| Startdatum | timestamp[ms] | Start date of the zone |
| Einddatum | timestamp[ms] | End date of the zone |
| Soort | string | Zone type: LEZ or ZES |
| Shape__Area | double | Area in m² |
| Shape__Length | double | Perimeter in m |
| geometry | binary | MultiPolygon in EPSG:28992 (RD New), WKB encoded |
