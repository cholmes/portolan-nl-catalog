# Primary Flood Defenses

Primary water barriers (primaire keringen) across the Netherlands — 238 dike sections that form the backbone of Dutch flood protection under the Water Act (Waterwet). LineString features with safety norms per section.

## Schema

| Column | Type | Description |
|--------|------|-------------|
| OBJECTID | int64 | Feature ID |
| TRAJECT_ID | string | Dike section identifier (e.g. "1-1", "95-1") |
| NORMTYP_O | string | Norm type: Faalkans (failure probability) or Overstromingskans (flood probability) |
| NORM_SW | int32 | Norm value — Significant Wave height |
| NORM_OG | int32 | Norm value — Overtopping/Overflow |
| NORM_THB | int32 | Norm value — Technical/Hydraulic Boundary |
| NORM_NS | int32 | Norm value — New Standard |
| WET_JN | string | Under Water Act (Ja/Nee) |
| VERSIE | string | Version |
| Shape__Length | double | Section length in metres |
| geometry | binary | LineString in EPSG:28992 (RD New), WKB encoded |
